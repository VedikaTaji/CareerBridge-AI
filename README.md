
# CareerBridge AI

AI-Powered Career Guidance, Job Role Matching and Skill Gap Analyzer.

## Problem Statement

Students often struggle to identify suitable career opportunities and understand the skills required for specific job roles.

CareerBridge AI analyses student profiles and job descriptions to recommend suitable career paths and identify missing skills.

## Technologies

- Python
- Machine Learning
- Neural Networks
- Natural Language Processing
- Retrieval-Augmented Generation (RAG)
- Large Language Models (LLM)
- Streamlit

## Main Features

1. Job Role Classification
2. Skill Matching
3. Skill Gap Analysis
4. AI Career Assistant
5. Evidence-Based Job Recommendations
